PlasticHouse(이하 “운영자”)는 Luckywood 게임과 연결된 로그인·게임 기록 저장 서비스에서 처리하는 개인정보를 아래와 같이 안내합니다. 이 방침은 Android 앱 Luckywood 및 해당 앱이 사용하는 eazysolve.com/newgame 게임 서비스에 적용됩니다.

공개 Native174에는 광고 SDK와 인앱결제가 없습니다. Android 검수 빌드267에는 Google Mobile Ads SDK와 사용자 메시징 플랫폼(UMP)이 포함됩니다. 이용자가 광고 설정을 선택하면 Google에 동의 상태 확인 요청을 보내며, 허용된 경우에만 테스트 광고를 준비합니다. 테스트 광고에는 추가 골드 지급이 없습니다. 실제 보상형 광고는 검증과 별도 운영 활성화 후 제공하며, 기본 귀환 보상은 광고 없이 지급합니다. 현재 인앱결제는 없습니다.

간편 로그인 선택선택한 Google·카카오·네이버가 제공하는 계정 식별자, 로그인 공급자, 인증·연결 상태선택한 계정 인증과 게임 계정 연결. 공급자의 비밀번호를 게임이 직접 수집하지 않습니다.
서버 저장·온라인 기능계정에 연결된 게임 진행, 저장 시각·버전, 순위·전투·마을 활동 기록, 닉네임, 사용자가 작성한 채팅기기간 기록 동기화, 순위·온라인 게임 기능, 오류·분쟁 대응 및 부정 이용 방지
서비스 연결·보안세션·인증용 임시 식별자, 접속 IP 또는 그 해시, 요청 시각과 요청·오류 정보 등 서버·네트워크 처리 정보통신·로그인 유지, 요청 제한, 보안 및 장애 대응. 게임의 인증 요청 제한에는 IP 해시를 사용합니다.
광고 설정·시청을 선택한 경우Google SDK가 처리하는 접속 IP와 그로부터 추정할 수 있는 대략적 위치, 앱·광고 상호작용, 진단 정보, 기기·광고 식별자 및 동의 상태동의 선택 처리, 광고 제공·측정·진단·부정 이용 방지. 실제 처리 항목은 기기 설정과 동의 상태에 따라 달라질 수 있으며 Google 방침이 적용됩니다. 테스트 광고도 SDK 통신이 없다는 뜻은 아닙니다.
추가 보상형 광고가 활성화된 버전서버의 귀환 체크포인트·보상 영수증, 영수증별 임의 가명 식별자·토큰 해시, 광고 거래 식별자, 지급 시각·금액·일일 제한 내역기본 보상 검증, 광고 완료의 서버 확인과 중복 지급 방지. Google에는 영수증별 임의 식별자와 임의 토큰을 전달하며, 게임 계정 원본 식별자·전체 저장 기록·이메일을 광고 검증 값으로 전달하지 않습니다. 현재 검수 빌드의 실제 광고 보상 지급은 꺼져 있습니다.
이메일 문의발신 이메일, 문의 내용 및 이용자가 제공한 계정 확인 정보문의, 권리 행사 및 삭제 요청 처리

기기 기록으로 플레이할 수 있으며, 계정 로그인과 서버 저장은 해당 기능을 선택할 때 사용합니다. 앱은 게임 이용을 위해 연락처·사진·마이크·정확한 위치를 요청하지 않습니다. 문의나 채팅에 비밀번호·복구 코드 등 불필요한 민감정보를 입력하지 마세요.

2. 다른 이용자에게 표시되는 정보

온라인 순위·전투·마을 기능에서는 닉네임 또는 게임 아이디와 레벨·순위·진행도·장비 등 공개 게임 정보가 다른 이용자에게 표시될 수 있습니다. 채팅에 작성한 내용은 다른 이용자가 볼 수 있습니다. 이메일, 비밀번호, 복구 코드 및 전체 개인 저장 기록을 공개 순위 정보로 제공하지 않습니다.

3. 서비스 제공업체와 외부 로그인

운영자는 게임 서버와 데이터베이스 제공에 Cloudflare의 네트워크·호스팅 및 D1 서비스를 사용합니다. 로그인 공급자는 이용자가 선택한 인증 과정에 참여하며, 각 공급자의 서비스에는 해당 개인정보처리방침이 적용됩니다. 문의 메일은 Google Gmail을 통해 처리합니다. 이 안내 페이지는 GitHub Pages에 호스팅되며 방문 시 호스팅 제공자가 접속 정보를 처리할 수 있습니다.

Google의 광고·동의 SDK는 이용자가 광고 설정을 선택한 경우 동의 확인과 광고 기능에 참여합니다. 이들 제공업체의 글로벌 인프라에 따라 정보가 대한민국 이외의 국가에서 처리될 수 있습니다. 운영자는 개인정보를 판매하지 않습니다. 광고 SDK의 정보 처리는 위 처리 항목과 Google의 방침을 참고해 주세요. 법령에 따른 적법한 요청이 있는 경우 필요한 범위에서 제공할 수 있습니다.

4. 보유 기간과 파기

계정 및 서버 게임 기록은 계정 기능을 제공하는 동안 보관합니다. 계정·데이터 삭제 요청을 받으면 본인 확인 후 해당 계정과 연결된 개인정보를 지체 없이 삭제하거나 개인을 알아볼 수 없도록 처리합니다. 구체적인 삭제 범위는 삭제 요청 안내에서 확인할 수 있습니다.

인증 세션·간편 로그인 연결 정보·요청 제한 정보는 기능에 필요한 유효기간 동안 사용합니다. 유효기간 종료는 접근 권한의 만료를 뜻하며 저장 매체에서의 즉시 물리 삭제를 의미하지는 않습니다. 채팅 조회 화면에는 최근 7일 범위의 메시지가 표시되며, 이 표시 기간을 서버 삭제 기간으로 안내하지 않습니다. 문의 정보는 요청 처리에 필요한 동안 보관한 후 불필요해지면 파기합니다.

법령상 보존 의무나 구체적인 보안·분쟁 대응 사유로 일부 정보 보관이 필요한 경우, 해당 목적에 한해 필요한 범위와 기간 동안 분리하여 보관하고 사유가 종료되면 파기합니다. 삭제 요청 시 보관 예외가 있으면 그 사유와 적용 기간을 안내합니다. 기기 안의 저장 파일은 앱 데이터 삭제 또는 앱 삭제로 제거할 수 있으나, 이것만으로 서버 계정이 삭제되지는 않습니다.

광고 검증용 토큰과 영수증의 유효기간은 광고 자격·지급 검증 기간을 뜻하며 서버 기록의 즉시 물리 삭제를 뜻하지 않습니다. 계정과 연결된 체크포인트·영수증·지급 내역도 계정 개인정보 삭제 요청 대상에 포함됩니다. Google 등 외부 제공업체가 별도로 처리하는 정보에는 해당 업체의 보유·삭제 절차가 적용됩니다.
